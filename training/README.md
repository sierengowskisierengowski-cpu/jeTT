# training/ — jeTT Training & Evaluation Infrastructure

> **Status: OPTIONAL** — These scripts are used to fine-tune and evaluate the
> jeTT AI model.  They are not required to run the jeTT daemon.

## Overview

jeTT uses [IBM Granite 3.3 2B](https://huggingface.co/ibm-granite/granite-3.3-2b-instruct)
as its base model, fine-tuned on synthetic security event datasets generated by
the scripts in this directory.

Training is performed via [Unsloth](https://github.com/unslothai/unsloth) on a
RunPod GPU instance or equivalent.  The resulting model is exported to GGUF
format for local inference with `llama-cpp-2`.

## Quick Start (CPU-only, no model required)

Run the lightweight unit tests — these do **not** require a GPU or a model file:

```bash
cd training/
python -m pytest test_training_pipeline.py test_jett_brain.py -v
# or
python -m unittest test_training_pipeline.py -v
```

## Full Training (GPU required)

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Generate a dataset:

   ```bash
   python generate_training_data.py
   ```

3. Run training on RunPod (see `scripts/runpod_train.sh`) or locally.

4. Export to GGUF:

   ```bash
   bash scripts/export_gguf.sh
   ```

## Dependencies

See `requirements.txt` in this directory.  Heavy ML dependencies
(`unsloth`, `torch`, CUDA) are listed under `[optional]` and are only needed
for training/fine-tuning, not for running the daemon.
